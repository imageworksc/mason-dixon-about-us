# Mason Dixon Animal Emergency Hospital — About Us

Static "About Us" page for Mason Dixon Animal Emergency Hospital, styled to match
[masondixonveter.com](https://www.masondixonveter.com/) and its [Careers page](https://www.masondixonveter.com/careers).

- `index.html` — page markup (content from "About Mason Dixon Animal Emergency Hospital.pdf")
- `styles.css` — design tokens and styles (Be Vietnam Pro + Inter, navy #242667 / red #c01d2e)
- `script.js` — mobile menu and scroll-reveal animations
- `assets/` — logos and photography from masondixonveter.com

Served with GitHub Pages from the `main` branch root.
