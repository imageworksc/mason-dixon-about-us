# Mason Dixon Animal Emergency Hospital — About Us

Static "About Us" page for Mason Dixon Animal Emergency Hospital, styled to match
[masondixonveter.com](https://www.masondixonveter.com/) and its [Careers page](https://www.masondixonveter.com/careers).

- `index.html` — page markup (content from "About Mason Dixon Animal Emergency Hospital.pdf").
  The facility section embeds an isometric SVG of the A101 floor plan with hoverable zones.
- `header.css` — header, mega menu and mobile drawer, ported from the masondixonveter.com theme
- `styles.css` — design tokens and page styles (Be Vietnam Pro + Inter, navy #242667 / red #c01d2e)
- `script.js` — header menu, floor-plan hover card, count-up stats and scroll-reveal animations
- `assets/` — logos, icons and photography

Served with GitHub Pages from the `main` branch root.
